# Suggested Commands for GBC Controller

## Development Commands
- `bun dev` - Start development server with Vite
- `bun run build` - Type check and build for production
- `bun run build:unsafe` - Build without type checking
- `bun run lint` - Run ESLint on the codebase
- `bun run preview` - Preview the production build locally

## Publishing
- `bun run publish:win` - Build and compile for Windows (creates mocaController executable)

## System Commands (Windows)
- `dir` - List directory contents (equivalent to `ls` on Unix)
- `cd` - Change directory
- `findstr` - Search text in files (equivalent to `grep` on Unix)
- `where` - Find location of executable (equivalent to `which` on Unix)
- `git` - Git version control commands

## Package Management
- `bun install` - Install dependencies
- `bun add <package>` - Add new dependency
- `bun remove <package>` - Remove dependency

## Common Git Commands
- `git status` - Check repository status
- `git add .` - Stage all changes
- `git commit -m "message"` - Commit changes
- `git push` - Push to remote repository
